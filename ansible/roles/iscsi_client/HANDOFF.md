## Do not rediscover these

- `iscsid` **only works in the host network namespace.** The kernel's
  `NETLINK_ISCSI` socket lives there. The initiator container runs with
  `network_mode: host`; that is not optional.
- The host **must not run its own `iscsid`** while the scenarios run.
- `tgt` **cannot serve a disk at LUN 0**; LUN 0 is its controller. The scenarios
  use LIO through `targetcli`, and LIO state is global to the kernel: if a run
  dies before cleanup, the next `prepare` removes the leftovers by IQN, and
  `targetcli clearconfig confirm=true` wipes everything. One target container
  per scenario, for the same reason.
- The by-path link **needs the host's `/dev`** in the initiator container.
- A node record is written as `<ip>,<port>` and moved to `<ip>,<port>,<tpgt>/`
  on the first login. The `creates:` guard is a glob.
- `_netdev` **never shows in the mount table.** Assert it in `/etc/fstab`.
- `ansible-lint --offline .` reports five failures. None is a defect; see the
  "Linting" section of `CLAUDE.md`.

## Running the tests

```
mise run fast                    # local + default, about 3 minutes
mise run scenario portals        # the named ones
mise run full                    # all four, about 8 minutes
```

`molecule test -s local` alone takes seconds and needs no container. Use it for
anything about the input contract.

The Docker scenarios need: Docker, the host's `/lib/modules` readable, a kernel
with `iscsi_tcp`, `target_core_mod`, `target_core_file` and `iscsi_target_mod`,
udev running on the host, and no `iscsid` on the host.
