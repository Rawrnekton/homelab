## Do not rediscover these

- `wg-quick@wg0` is a **oneshot unit with `RemainAfterExit`**. `service_facts`
  reports it as `stopped` while it is active. Assert `enabled` and the
  interface, not `running`.
- `ansible.utils.ipaddr('host/prefix')` **adds `/32` to a bare host** instead of
  rejecting it, and `ipaddr` is a filter, not a test.
- ansible-core 2.19+ **refuses a conditional that is a string**. `is truthy`.
- A privileged container **creates a WireGuard interface without
  `/lib/modules`**; the kernel loads the module from the host side.
- After a restart the server **does not know the client's endpoint** until the
  client sends a packet. Ping from the client first.
- `ansible-lint --offline .` reports three failures. None is a defect; see the
  "Linting" section of `CLAUDE.md`.

## Running the tests

```
mise run fast                    # local + default, about 3 minutes
mise run scenario roadwarrior    # the named ones
mise run full                    # all four, about 10 minutes
```

`molecule test -s local` alone takes seconds and needs no container. Use it for
anything about the input contract.

The Docker scenarios need: Docker, and the host kernel with the `wireguard`
module available (`prepare.yml` probes for it and says so when it is not).
